The layout is chosen by page folder in `app.ts`:
- `public/*` → `PublicLayout`;
- `auth/*` → `AuthLayout`;
- everything else → `AppShell`.

A page can override this with `defineOptions({ layout })`.

## 2. Shared prop types (`types/index.d.ts`)

```ts
export interface SharedProps {
  auth: { user: AuthUser | null; impersonating: { originalName: string } | null };
  workspace: { type: 'team' | 'department'; id: number; slug: string; name: string } | null;
  can: Record<string, boolean>;
  features: Record<string, boolean | number>;
  flash: { success?: string; error?: string };
  locale: 'en' | 'ar';
  dir: 'ltr' | 'rtl';
  honeypot?: { enabled: boolean; nameFieldName: string; validFromFieldName: string; encryptedValidFrom: string };
  turnstile?: { siteKey: string };
  nav: NavItem[];            // computed on the server from permissions and features
}
export interface MoneyDTO { amountMinor: number; currency: 'LYD' | 'USD' | 'EUR'; formatted: string }
export interface Paginated<T> { data: T[]; meta: { current_page: number; last_page: number; per_page: number; total: number }; links: { prev: string | null; next: string | null } }
```

Module resource types live in `types/models.d.ts`, one interface per API Resource with matching keys (for example `RobotResource`, `RegistrationResource`).

## 3. Navigation
`HandleInertiaRequests::nav()` builds the sidebar on the server from the active workspace:

| Workspace | Items (shown only when allowed) |
| --- | --- |
| Team | Dashboard, Members, Projects, Robots, Parts catalogue (`parts.access`), Events (`events.register` or any registration), Budget (`budget.manage` and `budget.request`), Settings (`team.settings`) |
| Department | Dashboard, then each area the user can view: Teams, Events, Catalogue, Finance, Content, Inbox, Reports; Members and permissions (admins) |
| Super admin (global) | All console areas, plus Departments, Tiers, Users, Audit, Settings |

`WorkspaceSwitcher` lists `auth.user.workspaces` (lazy prop) and switches by visiting the URL. Nothing is stored in the session.

## 4. Composables

| Composable | Contract |
| --- | --- |
| `useHoneypotForm<T>(data: T)` | `useForm({...data, [hp.nameFieldName]: '', [hp.validFromFieldName]: hp.encryptedValidFrom})` when `honeypot.enabled`; the component renders the hidden inputs |
| `usePermissions()` | `can(ability: string): boolean` reads `page.props.can` |
| `useFeatures()` | `has(name)`, `limit(name)` |
| `useMoney()` | `format(dto)` returns `dto.formatted`; `toMinor(input: string, currency)` and `fromMinor(n, currency)` use the currency scale (LYD 3); there is no float arithmetic beyond parsing user input |
| `useDates()` | `format(iso, pattern)` with `Intl.DateTimeFormat(locale, { numberingSystem: 'latn', … })` (D-11) |
| `useLocale()` | `locale`, `dir`, `switchTo(l)` (public pages: swap the URL prefix; app pages: `POST account.locale`) |
| `useTableQuery(defaults)` | A reactive query (`q`, `sort`, `dir`, `page`, `filters`) synced to the URL; debounced `router.get(url, query, { preserveState: true, preserveScroll: true, replace: true })` |
| `useFlashToasts()` | Watches `flash` and calls `toast.success` or `toast.error` (vue-sonner) |
| `useConfirm()` | A promise-based `ConfirmDialog` for destructive actions |

## 5. Key components

| Component | Behaviour |
| --- | --- |
| `DataTable` | Props `columns` (TanStack Vue Table `ColumnDef`), `rows: Paginated<T>`, `query`. Server sort and pagination only. A row-action slot. Shows `EmptyState` when there are no rows and skeleton rows while loading (Inertia `router.on('start'/'finish')`) |
| `FormField` | Label, control slot, help, and error from `form.errors[name]`; wires `id`, `aria-describedby` and `aria-invalid` |
| `LocalizedInput` | EN and AR tabs; the AR input has `dir="rtl"`; marks the EN tab required |
| `RichTextEditor` | Tiptap with a limited toolbar (headings 2/3, bold, italic, lists, link, quote, image from media). Outputs HTML; the server sanitises it again |
| `MediaUploader` | Drag-and-drop, client-side type and size checks, upload to `MediaController`, reorder, delete; returns media ids |
| `ComboboxAsync` | Searchable select fed by JSON endpoints (parts search, teams, users) with 25 per page and infinite scroll |
| `MoneyInput` | A text input with the currency suffix; validates the decimal scale; emits a decimal string, which the server converts to minor units |
| `Turnstile` | Loads `https://challenges.cloudflare.com/turnstile/v0/api.js` once, renders the widget, emits the token into `form['cf-turnstile-response']`, and resets after a submit error |
| `BomEditor` | Rows: part (ComboboxAsync), offer select, quantity, notes, drag handle; footer totals per currency come from the server response after save, never computed on the client |
| `SplitEditor` | Editable lines (account, amount) from the proposal; shows the remaining amount (in minor units, BigInt-safe); disables submit until the remaining amount is zero |
| `PermissionMatrix` | Members × (area.view, area.edit), only for areas in the ceiling; a row save sends `PUT …/permissions` |
| `EligibilityTable` | Per category: members and robots with ✓ or ✗ and the translated reason code from `EntryRules` |
| `ImpersonationBanner` | A fixed top bar when `auth.impersonating`, with a "Leave" button (`POST impersonate.leave`) |

## 6. Styling, RTL and accessibility
- **Tailwind 4 theme tokens** (CSS variables in `resources/css/app.css`):
  - `--brand: #f8660b`, `--brand-ink: #b54708`, the warm neutrals from the v1 redesign, and the shadcn `--background`/`--foreground` mapped to them;
  - dark-mode values under `.dark`.
- **Public styles:** `resources/css/public.css` is ported from v1 as component-scoped classes under `@layer components` for the public layout only.
- **RTL:** only logical utilities. The ESLint rule `tailwindcss/no-physical-properties` (a custom regex rule in `eslint.config.js`) blocks `ml-`, `mr-`, `pl-`, `pr-`, `left-`, `right-`, `text-left` and `text-right`.
- **Fonts:** Manrope for EN; Noto Kufi Arabic for AR (`:lang(ar)`); tabular figures for money and tables.
- **Accessibility (NFR-A11Y-01):**
  - shadcn-vue (Reka) primitives provide focus management and ARIA;
  - every icon-only button has `aria-label`;
  - a skip link is in every layout;
  - `prefers-reduced-motion` turns off transitions;
  - the target contrast is 4.5:1, checked with the axe browser extension during phase checks.

## 7. Error and loading states
- `Error.vue` receives `{status, title, message}` from the exception renderer. It offers "Go home", which goes to the locale home on public URLs and to the hub on app URLs.
- A 419 shows "Page expired" and reloads.
- Inertia's progress bar uses the brand colour. Tables show skeletons; forms disable submit while `form.processing`.

## 8. Build and quality
- `vite.config.ts` uses `laravel-vite-plugin`, `@vitejs/plugin-vue`, `@tailwindcss/vite`, `@laravel/vite-plugin-wayfinder` and `laravel-vue-i18n/vite`.
- Code-split per page (Inertia `resolvePageComponent` with `import.meta.glob`). The public pages' chunk budget is 150 kB gzip (NFR-PERF-04), checked with `rollup-plugin-visualizer` in CI.
- Scripts:
  - `npm run build`;
  - `npm run lint` (ESLint with the Vue, TS and RTL rule);
  - `npm run format` (Prettier);
  - `npm run types` (`vue-tsc --noEmit`);
  - `npm run test` (Vitest for composables: `useMoney`, `useDates` with Western digits, `useHoneypotForm`, and `Timeline` ported from v1).
